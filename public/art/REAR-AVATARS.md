# Vistas de costas dos avatares

Arquivo integrado: `cartoon-team-back.webp`.
Ferramenta: image_gen integrada, com transparência, usando `cartoon-team.webp` como referência. A imagem original dos avatares foi preservada.

## Prompt utilizado

Use case: identity-preserve. Asset type: transparent game sprite sheet. Edit target: attached six fictional cartoon student avatars. Produce the SAME SIX fully clothed characters viewed strictly FROM BEHIND, heads looking away from the camera, no face visible, neutral full-body standing pose with legs slightly separated. Preserve each hairstyle, clothing, backpack, proportions, shoes, and polished 3D cartoon animation style. Exactly 3 columns by 2 rows, one centered figure in each equal square cell, same character order and size as reference. Top row: green tee amber backpack curly boy; purple hoodie curly girl; teal jacket red-haired boy. Bottom row: amber jacket braided girl; teal hoodie dark-haired glasses boy; olive overshirt brown-haired boy. Rear view must show the back of hair and backpack, never front faces. Transparent alpha background, no environment, no floor shadow, no text, no border, feet fully inside each cell, consistent scale. Output landscape 3:2 sheet.

As orientações laterais usam espelhamento separado das animações; a vista posterior usa esta arte. As pernas posteriores são recortes articulados via CSS. Não é rotação esquelética 3D nem captura de movimento.
