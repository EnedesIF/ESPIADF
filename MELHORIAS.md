# MISSÃO DF — melhorias desta versão

## O que foi melhorado
- Novo **briefing cinematográfico** entre a Central de Missões e o mundo 3D.
- Linguagem de operação/investigação, sem estética infantil.
- Cada campanha agora tem um quadro de **o que sabemos** e **o que ainda não sabemos**.
- Exibição do esquadrão e dos papéis dos integrantes antes da missão.
- Reforço da regra pedagógica central: relato não é prova; dados precisam de contexto; conclusões devem ser sustentadas por evidências.
- Entrada na cidade com CTA visual de missão, mantendo a arquitetura 3D existente.
- Interface responsiva e compatível com redução de movimento.

## Observação de build
O projeto mantém o mesmo package.json. Execute `npm install` (ou `npm ci`) em uma máquina com acesso ao registro npm e depois `npm run dev` / `npm run build`.
