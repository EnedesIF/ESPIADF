ESPIA DF — Saúde, nova abertura e avatares — 30/10/2026

ATUALIZAÇÃO CUMULATIVA. Inclui as revisões anteriores de lixo/coleta, quadra, território, UBS e cenário 1 contidas nos pacotes anteriores. Não é o repositório completo: mantenha os demais arquivos do projeto.

COMO PUBLICAR
1. Extraia este ZIP.
2. Envie os arquivos extraídos para a raiz de EnedesIF/ESPIADF, mantendo os caminhos das pastas.
3. Substitua os arquivos correspondentes, incluindo package.json e public/art/espia-opening-gdf-v32.webp. Não envie apenas o ZIP fechado e não apague o repositório.
4. Confirme o commit e aguarde o deploy automático da Vercel concluir.
5. Teste o site publicado. Este pacote ainda não foi enviado ao GitHub automaticamente.
